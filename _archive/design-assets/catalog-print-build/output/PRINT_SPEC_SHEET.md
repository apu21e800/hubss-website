# HUBSS Catalogue 2026 — Print Spec Sheet

For the printer / press operator.

## Document

- **File:** `HUBSS_Catalogue_2026.pdf`
- **Pages:** 100 (divisible by 4 — saddle-stitch ready, also works for perfect bind)
- **Trim size:** 5.000" × 5.000" square
- **Bleed:** 0.125" on every side
- **Document size:** 5.250" × 5.250" (trim + bleed)
- **Safe area:** 0.250" inside trim (text + logos do not cross this)
- **Resolution:** 300 DPI raster, vector text + shapes
- **Color space:** Built CMYK; printer's RIP should preserve CMYK profile
- **Crop marks:** Included at corners (0.25 pt hairlines, outside trim)

## Recommended Paper Stock

**Premium option (recommended):**
- Cover: **Mohawk Superfine White Eggshell, 100lb cover** (or equivalent uncoated matte)
- Text: **McCoy Silk, 100lb text** (dull-coated for photo-rich pages without shine)

**Mid-tier option:**
- Cover: 100lb dull/matte cover
- Text: 80lb dull/matte text

**Why matte / dull:**
- Editorial feel — premium catalogues use matte not gloss
- Reduces glare under trade-show lighting
- Cream paper tone reads warmer on uncoated stock

## Finishing

- **Binding:** Saddle-stitched (2 staples, page count divisible by 4 ✓) — best for ≤ 64 pages
- **Or:** Perfect bound for square-spine premium feel — recommended at 100 pages
- **Score / fold:** Standard cover scoring if perfect bound
- **Coating:** None on cover — matte uncoated only
- **Optional:** Soft-touch laminate on cover (premium tactile finish, +20-30% cost)

## Color Notes

- HUBSS Orange `#F97316` ≈ Pantone 165 C / CMYK 0/65/100/0
- HUBSS Navy ≈ Pantone 296 C / CMYK 65/45/20/92
- Cream paper background built into the artwork (CMYK 2/4/10/2) — works on any white sheet
- Photos are RGB; printer's RIP handles CMYK conversion (or pre-flatten if requested)

## Production File Checklist

- [x] All photos embedded
- [x] CMYK fonts via PDF (Helvetica fallback; Inter substitute)
- [x] Crop marks at corners
- [x] Bleed extends to all four edges where photos run full-bleed
- [x] No spot colors used (process CMYK only)

## Pre-Press Notes

- The PDF is single-page format (not spreads). Printer should impose for binding.
- All hairlines are minimum 0.3 pt — safe for offset printing.
- Smallest text size used: 5.6 pt tracked-caps copyright (above the printer-recommended minimum of 5 pt).
- Cover photo (UBC Crosswalk) bleeds to all four edges.
