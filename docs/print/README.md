# The QR code for the printed Idea Book

`idea-book-qr.svg` (vector, use this in the print file) and `idea-book-qr.png`
(2000 px) both open `hubss.com/idea-book` with a `utm_source=print` tag, so
GA4 can count readers who came from the printed book. Print it on the back
cover or the inside front cover with the line:

    Read it on your phone, save it for offline: hubss.com/idea-book

Keep the quiet zone (the white margin) around the code, print it at 25 mm or
larger, dark on white. Never re-generate it with a different address: the
printed one has to keep working for as long as the book is on desks.
