# /public/docs — HUBSS Document Library

PDF spec sheets, brochures, and technical documents served directly from the website's Resources page.

**One subfolder per product. Drop a PDF in the right folder and it's live on the site. No code change needed.**

---

## How to Add or Update a PDF

1. Name the file in kebab-case, lowercase: `streetprint-spec.pdf` not `StreetPrint Spec.PDF`
2. Drop it into the correct product subfolder below
3. That's it — the Resources page reads this directory automatically

**To replace a file:** drop the new version with the exact same filename. The old one is overwritten.
